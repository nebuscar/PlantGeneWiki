# PlantsDB AI 助手

PlantsDB 植物基因数据库的智能分析助手，覆盖从序列到结构的全链路植物基因组分析。

## 主要功能

**基因数据库查询**
- 基因功能注释（GO、KEGG、Pfam 结构域）
- 同源基因比较（跨物种保守性、理化性质对比）
- 基因家族成员检索（按结构域或功能）
- RNA-seq 表达谱分析（组织特异性、处理 vs. 对照）
- GO/KEGG 富集分析

**序列分析**
- 多序列比对（MSA）：MAFFT 比对 + trimAl 修剪 + 可视化 PDF
- 系统发育树构建：IQ-TREE 最大似然树 + bootstrap 支持值
- 蛋白质三维结构预测：ESMFold（3.5B 参数模型），输出 PDB + pLDDT 置信度图

## 使用说明

登录后可使用全部分析功能（BLAST 搜索、序列下载、结果导出）。右上角 ⚙️ 设置中填入 API Key 即可开始对话。
