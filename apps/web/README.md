# PlantGeneWiki Web

Static-first web application for PlantGeneWiki.

This app is designed as a pre-rendered version of a future dynamic knowledge base. Pages consume stable object-shaped data from `public/data/api/`. Later, the same data shape can be served by Cloudflare Workers or another API without rewriting page components. The `public/data/api/` files are generated by `scripts/build/build_web_data.py` from normalized knowledge object records.

## Current Scope

- Home page
- Species page
- Gene page
- Dataset page
- Search page backed by a small static index
- Graph page backed by static node and edge samples

## Data Boundary

The web app must not read raw FASTA, GFF, PGCP raw JSON dumps, PDFs, or internal server paths directly. It should consume published data only:

```text
public/data/api/
|-- species/
|-- genes/
|-- datasets/
|-- search/
`-- graph/
```

Raw data remains outside Git and is described through Dataset records.

## Build Published Data

From the repository root:

```bash
python3 scripts/build/build_web_data.py
```

This rewrites `apps/web/public/data/api/` from `examples/knowledge_objects/`.

## Local Commands

```bash
npm install
npm run dev
npm run build
```

## Cloudflare Pages

Use `apps/web` as the Pages root directory.

- Build command: `npm run build`
- Output directory: `dist`
- Framework preset: Astro
