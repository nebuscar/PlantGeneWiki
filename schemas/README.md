# Schemas

JSON Schemas for PlantGeneWiki exchange records.

These schemas define the stable contract between normalized knowledge objects, static published data, and future dynamic APIs.

Current schema files:

- `knowledge_object.schema.json`
- `dataset.schema.json`
- `relation.schema.json`
- `evidence_claim.schema.json`

The first implementation intentionally uses a small shared object shape. Type-specific schemas can be added once real data conversion stabilizes.
