# PlantGeneWiki 项目定位

## 科学问题

PlantGeneWiki 的核心科学问题不是单纯整合植物基因组数据，而是：

> 将大语言模型的可靠推理边界推展至现有系统服务不足的复杂作物基因组学领域。

当前通用大语言模型在复杂作物基因组学任务中存在三个主要限制：

- 领域知识覆盖不足，尤其是油菜等复杂异源多倍体作物的专门知识。
- 证据链不可控，容易在基因、性状、文献和实验背景之间生成无法追溯的结论。
- 对结构化生物学关系的推理能力不足，难以稳定处理同源关系、QTL/GWAS 证据、基因功能、表达谱和文献证据之间的组合查询。

因此，本项目的目标是构建一个可持续更新、证据可追踪、面向复杂作物基因组学问答和推理的植物知识智能体。

## 研究思路

PlantGeneWiki 采用以下路线：

1. 整合多种来源知识，形成可自动更新的油菜及植物基因组学知识库。
2. 通过文献收集、筛选、评估和结构化抽取建立高质量领域语料。
3. 同时构建两类知识组件：
   - 面向语义检索的向量化知识库。
   - 面向关系推理的结构化知识图谱。
4. 结合多元语义检索、结构化知识图谱查询和大语言模型生成，构建植物知识智能体。
5. 通过可追溯证据链、检索命中、结构化查询结果和人工评估，约束和评估大语言模型输出。

## 重点应用领域

当前项目重点面向油菜领域，尤其是甘蓝型油菜及其复杂基因组背景：

- 油菜遗传学研究热点演化。
- QTL mapping、GWAS、进化和功能基因组学相关文献证据。
- 甘蓝型油菜二倍体祖先和油菜基因组发布后形成的研究主题变化。
- 油菜基因、性状、品种、表达、同源关系、GO/KEGG 通路和文献证据的融合查询。

## 文献筛选与评估

油菜文献进入知识库前需要经过自动化质量控制流程：

1. 关键词初筛。
2. 正则表达式过滤。
3. SciBERT 文本分类模型精筛。
4. 双阈值人机协同筛选：
   - 低置信度文献自动剔除。
   - 高置信度文献自动接受。
   - 中间不确定文献进入人工复核。

相比传统单阈值方法，双阈值 SciBERT 策略需要在召回率、准确率、精确率和 F1 分数上取得更稳定表现，同时降低人工复核工作量。

## 知识库构建目标

油菜知识库不是静态数据仓库，而是可持续更新的领域知识系统。目标组件包括：

- 文献语料库：高质量油菜遗传学和基因组学文献。
- 品种和种质记录：油菜品种、材料、性状等条目。
- 基因组与注释数据：基因、表达谱、同源关系、GO/KEGG 等。
- 向量知识库：用于语义检索、段落召回和证据定位。
- 结构化知识图谱：用于实体关系查询和多跳推理。
- 智能体接口：将检索、图谱查询和 LLM 生成组合为可审计问答流程。

## 工程原则

1. 数据整合不是最终目标，证据化推理才是最终目标。
2. 每个生成答案必须尽量返回可追溯证据来源。
3. 文献筛选、知识抽取、图谱构建和问答生成需要分别可测试。
4. 原始大数据保留在 `data/`，代码、配置、文档和测试保持轻量可提交。
5. 对外部服务的批量抓取必须限速、可断点续跑，并在服务异常时自动暂停。
