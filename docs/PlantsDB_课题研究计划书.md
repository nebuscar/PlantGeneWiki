## 一、项目摘要

PlantsDB 植物标准基因组库旨在整合约 2010 个植物物种的基因组数据，构建标准化、可查询的比较基因组学数据平台。项目覆盖基因组数据批量下载与标准化处理、蛋白质理化性质计算、功能注释、同源基因鉴定与比较基因组分析等完整工作流。

**关键词**：植物基因组、多倍体、泛基因组、同源基因鉴定、比较基因组学

## 二、立项依据

### 2.1 研究背景与意义

#### 2.1.1 植物基因组数据的重要性

植物是地球上最重要的光合作用生产者，支撑着全球生态系统和人类粮食安全。随着高通量测序技术的快速发展，越来越多的植物物种完成了基因组测序和注释。然而，这些数据分散存储在 NCBI、EBI、DDBJ 等多个数据库中，数据格式不统一、质量参差不齐，给比较基因组学研究带来了巨大挑战。

#### 2.1.2 植物基因组的特殊复杂性

与动物基因组相比，植物基因组具有独特的进化特征：

**（1）多倍体化现象普遍**

多倍体（Polyploidy）指生物体内拥有两套或两套以上完整染色体组的细胞或个体。据估计，约 35-50% 的显花植物在进化过程中经历过至少一次全基因组复制事件（Wood et al., 2009）。多倍体分为：
- **同源多倍体（Autopolyploid）**：由同一物种染色体组加倍形成，如马铃薯（AABB）
- **异源多倍体（Allopolyploid）**：由两个或多个不同物种杂交后染色体组加倍形成，如油菜（AACC）、小麦（AABBDD）

**（2）同源基因（Homeologs）的存在**

在异源多倍体中，来自不同祖先基因组来源的同源基因称为 homeologs。以芥菜（AABB）为例，其 A 亚基因组来自白菜（AA），B 亚基因组来自黑芥（BB），芥菜中有多个 homeolog 对应拟南芥的单个基因（如 PORC 基因在芥菜中分布于 A08、A10、B03、B06 四个染色体上），这使得同源基因鉴定和数据整合的难度远超二倍体物种。

**（3）泛基因组趋势**

泛基因组（Pan-genome）指某个物种所有成员基因组的完整集合，包括所有个体都有的核心基因（Core genes）和仅部分个体有的附属基因（Dispensable/specific genes）。单一参考基因组无法代表物种内全部遗传多样性，不同品种和野生种之间存在大量结构变异和基因 presence/absence 变异。

#### 2.1.3 现有植物数据库的局限

目前植物学领域已有多个单物种数据库（TAIR、Rice RGAP、BnIR、BjuIR、MaizeGDB 等），但存在以下局限：
- 各数据库侧重不同，缺乏统一的整合平台
- 跨物种比对能力有限
- 无法提供 "基因→功能→变异→性状→育种" 的完整知识链条
- 数据更新滞后，难以满足大规模比较基因组学研究需求

#### 2.1.4 PlantsDB 的定位与意义

PlantsDB 定位于**底层基因组数据基础库**，为比较基因组学研究提供标准化、可扩展的数据支撑：
- 统一数据格式和质量标准
- 解决多倍体物种的同源基因标注问题
- 提供跨物种同源关系查询
- 为上层应用（知识图谱、智能查询）提供可靠的数据底座

### 2.2 国内外研究现状

#### 2.2.1 基因组数据资源现状

| 数据库 | 覆盖范围 | 主要特点 |
|--------|----------|----------|
| NCBI GenBank/RefSeq | 全球所有测序物种 | 数据最全，但质量参差不齐 |
| Ensembl Plants | 重要植物物种 | 注释质量高，覆盖有限 |
| Phytozome | 植物物种 | 整合多个物种，支持 JBrowse 可视化 |
| PlantGDB | 植物 EST 和基因组 | 以 EST 为主，数据较旧 |

#### 2.2.2 比较基因组学分析工具现状

| 工具 | 功能 | 局限性 |
|------|------|--------|
| GeneTribe | RBH 同源基因鉴定 | 对多倍体处理有限 |
| OrthoFinder | 直系同源基因鉴定 | 计算资源消耗大 |
| JCVI/MCscan | 共线性分析 | 依赖高质量基因组注释 |
| eggNOG-mapper | 功能注释 | 注释率依赖输入数据质量 |

#### 2.2.3 智能查询系统现状

在生物医学领域，GeneCards 成功整合了基因名称、序列、疾病、药物等信息，提供了一站式基因知识查询平台。但在植物学领域，尚未有类似平台能实现从基因到性状到育种的完整知识链条。

### 2.3 特色与创新点

1. **大规模植物基因组资源整合**：首次系统整合 2010 个植物物种的标准化基因组数据，覆盖藻类、苔藓、蕨类、裸子植物、被子植物等多个分类层级。

2. **多倍体同源基因规范化处理**：针对异源多倍体物种（如油菜、芥菜、小麦等）的 homeologs 进行专门标注，建立亚基因组来源追踪体系。

3. **标准化数据管线**：建立从数据下载、格式统一、质量控制到结果汇总的完整自动化管线，确保数据可重复性和可追溯性。

4. **并行化分析流程**：实现边下载边分析的高效工作流，显著缩短项目周期。

## 三、研究目标与内容

### 3.1 总体目标

构建覆盖约 2010 个植物物种的标准化基因组数据库，实现：
- 基因组数据的批量下载、标准化存储与质量控制
- 蛋白质理化性质计算与功能注释
- 同属内近缘物种基因映射与同源基因鉴定
- 数据汇总与结果报告产出

### 3.2 研究内容

#### 3.2.1 基因组数据下载与整理

**目标**：完成约 2010 个植物物种的基因组数据下载与标准化处理。

**计划完成时间**：2026年4月底

**内容**：

1. **数据来源与下载工具**
   - 数据来源：NCBI Datasets CLI（`datasets` 命令）
   - 物种列表：基于已有物种列表（`species_list_with_taxid.txt`），包含物种名、Taxonomy ID、倍性、目、科、属等分类信息

2. **下载数据类型**
   - 基因组序列（genome.fna）
   - 蛋白序列（protein.faa）
   - CDS 序列（cds.fna）
   - GFF3 注释文件（annotation.gff）
   - GBFF 注释文件（annotation.gbff）

3. **筛选策略**
   - **组装级别**：优先选择 chromosome、complete 级别
   - **数据来源**：RefSeq 优先，GenBank 备选
   - **版本选择**：优先使用最新版本（latest）
   - **排除条件**：排除非典型组装（atypical）、多分离株项目
   - **物种列表**：按属（genus）分批下载，支持从文件读取批量列表

4. **版本选择机制**
   - 每个物种可能存在多个 accession（GCF_*/GCA_*）
   - 评分机制：完整性优先（gff +2分，gbff +1分，fna/cds.faa/faa 各 +1分）
   - 同分时 RefSeq（GCF）优先于 GenBank（GCA）

5. **标准化命名规范**
   - 文件统一命名为：`{SpeciesName}_{data_type}.{ext}`
   - 例如：`Acer_negundo_genome.fna`、`Oryza_sativa_protein.faa`

6. **断点续传与日志**
   - 检测 `{species}_genome.fna` 存在则跳过已下载物种
   - 维护四类日志：total.log（总览）、success.log（成功）、fail.log（失败）、skip.log（跳过）
   - 生成 README_SOURCES.txt 记录数据来源、下载时间、accession 等溯源信息

#### 3.2.2 功能注释模块

**计划完成时间**：2026年5月初（与下载同步进行）

##### 3.2.2.1 基因坐标提取

从 GFF/GBFF 注释文件中提取基因位置信息，包括：
- 染色体位置（染色体号、起始位点、终止位点、链方向）
- 基因结构（外显子数量、内含子位置、UTR 区域）
- 基因类型（蛋白编码基因、假基因、非编码 RNA 基因等）

##### 3.2.2.2 CDS 和 PEP 序列提取

基于 GFF 注释文件，从基因组序列中提取：
- CDS（Coding Sequence）序列
- PEP（Protein Sequence）序列

建立 locus_tag 与 protein_id 的双向映射关系表。

##### 3.2.2.3 eggNOG-mapper 功能注释

使用 eggNOG-mapper 对蛋白序列进行批量功能注释，产出：
- GO（Gene Ontology）功能注释
- KEGG 代谢通路注释
- COG（Clusters of Orthologous Groups）分类

##### 3.2.2.4 蛋白质理化性质计算

使用 BioPython 计算每个蛋白质的：
- 等电点（pI）
- 分子量（MW）
- 氨基酸长度
- 氨基酸组成

#### 3.2.3 同属内近缘物种基因映射表

**计划完成时间**：2026年5月初（与下载和分析同步进行）

**目标**：建立同属内物种间的基因对应关系。

**内容**：
1. 使用 GeneTribe 进行 RBH（Reciprocal Best Hit）同源基因鉴定
2. 区分直系同源（Orthologs）和旁系同源（Paralogs）
3. 对多倍体物种，标注 homeologs 的亚基因组来源
4. 生成跨物种基因映射表
