# 植物知识智能体架构

## 总体目标

PlantGeneWiki 智能体面向复杂作物基因组学问题，尤其是油菜领域问题，提供可追溯、可检索、可结构化验证的回答。

系统不应只把大语言模型作为聊天接口，而应把它放在受控推理流程中：

```text
用户问题
  -> 意图识别
  -> 语义检索 / 知识图谱查询 / 结构化工具调用
  -> 证据整合
  -> LLM 生成
  -> 证据链和不确定性输出
```

## 核心模块

### 1. 文献获取与筛选

职责：

- 从 PubMed、Crossref 或其他文献库监测新增油菜相关文献。
- 使用关键词和正则表达式做初筛。
- 使用 SciBERT 分类器进行领域相关性判断。
- 使用双阈值策略降低人工复核压力。

输出：

- 高置信度油菜文献集合。
- 需要人工复核的文献集合。
- 低置信度剔除集合。
- 筛选指标，包括召回率、准确率、精确率、F1 分数和人工复核比例。

### 2. 文档解析与知识抽取

职责：

- 将文献解析为标题、摘要、正文段落、图表说明和参考信息。
- 切分文本块并保留来源、位置和上下文。
- 抽取实体和关系：
  - 基因。
  - 性状。
  - QTL。
  - GWAS 位点。
  - 品种和材料。
  - 表达组织或条件。
  - GO/KEGG 通路。
  - 同源关系。

输出：

- 可向量化文本块。
- 结构化实体表。
- 结构化关系表。
- 抽取置信度和证据来源。

### 3. 向量知识库

职责：

- 支持基于自然语言问题的语义检索。
- 返回可追溯文献片段、数据条目和上下文。
- 与 BM25、关键词匹配或字段过滤结合，避免纯向量检索漏召回。

适用问题：

- “某个基因与抗病性有什么关系？”
- “哪些文献支持某个 QTL 与含油量相关？”
- “油菜 GWAS 研究热点在 2011-2025 年如何变化？”

### 4. 结构化知识图谱

职责：

- 存储实体与关系。
- 支持确定性查询和多跳推理。
- 与向量检索结果互相校验。

典型关系：

```text
Gene -> associated_with -> Trait
Gene -> homolog_of -> Gene
QTL -> located_on -> GenomicRegion
Variant -> associated_with -> Trait
Cultivar -> has_trait -> Trait
Paper -> reports -> Finding
Finding -> supported_by -> EvidenceSpan
```

适用问题：

- “某个性状关联了哪些基因和 QTL？”
- “某基因在不同油菜材料中的表达证据有哪些？”
- “某个候选基因是否同时有同源、表达和文献证据支持？”

### 5. LLM 生成层

职责：

- 根据检索证据和图谱查询结果生成回答。
- 明确区分事实、推断和不确定性。
- 返回引用证据和数据来源。
- 当证据不足时拒绝过度推断。

输出要求：

- 结论。
- 支持证据。
- 数据来源。
- 不确定性。
- 可继续验证的分析步骤。

## 评估维度

### 文献筛选评估

- 召回率。
- 准确率。
- 精确率。
- F1 分数。
- 人工复核工作量。

### 检索评估

- 查询召回率。
- Top-k 命中质量。
- 证据片段可用性。
- 与关键词检索和 BM25 的互补性。

### 图谱评估

- 实体规范化准确率。
- 关系抽取准确率。
- 多跳查询正确率。
- 证据链完整性。

### 智能体评估

- 回答事实正确性。
- 证据可追溯性。
- 幻觉率。
- 不确定性表达质量。
- 对复杂作物基因组学问题的可解释推理能力。

## 当前工程状态

当前仓库已有或正在整理的能力包括：

- PGCP 原始基因 JSON 下载和断点续跑脚本。
- IMP、MSA、ESMFold 等分析脚本。
- Agent 原型目录 `apps/agent/`。
- 数据来源、开发指南和维护日志文档。

后续应优先补齐：

1. 文献筛选流水线。
2. SciBERT 双阈值分类模块。
3. 文本切分和证据片段索引。
4. 知识图谱 schema 和导入流程。
5. 智能体工具注册与回答评估集。
